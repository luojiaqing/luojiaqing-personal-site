一个神经元只做两件事：把输入按权重加起来，再过一次激活函数。拖动下面的滑块，看权重和偏置如何改变它的输出。

SHAPE RULE

每层参数量 = (输入数 + 1) × 输出数。加 1，是因为每个输出神经元都有一个偏置。

!

初始化别全填 0：同一层神经元起点一样，梯度也会一样，最后学成同一个模样。

按 float32 算，105 个参数约 420 bytes。模型很小，难的是找到这 105 个数。
A

W 是矩阵。行是输出神经元，列是它接收的输入；颜色深浅只是数值大小。

B

b 是向量。每个输出神经元一个，把激活门槛往左或往右推。

C

激活函数不是参数。没有它，多层网络叠起来仍然是一条直线。

05 / 学习率

            
步子太大飞出去，
太小走不动。

          

          
学习率 η 是超参数，不是学出来的。下面是一条二次函数山谷：拖动步长，看参数 θ 怎么走。真实的损失面有 105 维，这里只切了一刀。

        


        

          

            
01
太小
每次都挪一点，方向没错，但要走很多步才到底。

            
02
刚好
几步滑到谷底，稳定、可重复，损失单调下降。

            
03
太大
一步跨过谷底，在两边来回弹；再大就飞出去。

            

              UPDATE RULE
              θ ← θ − η · 2θ
              f(θ) = θ²，梯度 = 2θ；这是示意图，不是 105 维真实损失面
            

            

              TUNING ORDER
              
01
先标准化输入。特征尺度差太多，同一个 η 不可能适合所有参数。

              
02
再找合适量级。0.001 → 0.01 → 0.1，按 3× 或 10× 跳，不要线性微调。

              
03
最后看两条曲线。训练和测试一起看，别只盯训练损失。

              
04
先跑通小网络。1–2 个隐藏层、几十个参数，先看见边界怎么变，再加深。

              
05
权重图看模式。行与行、层与层的关系，比单个格子可靠。

06 / 速查

            
一页带走，
顺便避开这些坑。

          

          
如果只记三句话：参数是 W 和 b；训练是四步循环；看图要同时看损失、边界和权重模式。

        


        

          

            
01
参数 vs 超参数

            

              
谁决定训练中变吗

              
                
参数 W / b梯度下降变

                
超参数人 / 搜索不变

              
            

            
学习率、层数、隐藏单元、激活函数、batch size 都是超参数。

          


          

            
02
5 个常见坑

            
    
              
  • ×全 0 初始化。隐藏神经元永远对称，等于白加一层。
    • 
              
  • ×学习率太大。损失震荡、爆炸，甚至 NaN。
    • 
              
  • ×只看训练损失。测试集才是“没见过的题”。
    • 
              
  • ×把权重当因果。相关特征会分摊权重，尺度也会改变数值。
    • 
              
  • ×用测试集调参。反复看测试集，它就不再是“没见过”的题。
    • 
            

          


          

            
03
一页总结

            

              
参数每层一个矩阵 W + 一个向量 b；本例共 105 个。

              
训练前向 → 损失 → 反向 → 更新，循环到收敛。

              
看图损失看趋势，边界看形状，权重看模式。

              
边界权重颜色 ≠ 特征重要性；用消融或置换再验证。
